Méthode 1 · le favori magique conseillée

  1. Affiche ta barre de favoris : Ctrl+Maj+B (sur Mac ⌘+Maj+B).
  2. Glisse ce bouton dans la barre de favoris : Exporter Kyara
  3. Va sur kyara.games en étant connecté, puis clique sur le favori « Exporter Kyara ». Un fichier kyara-collection.json se télécharge.
  4. Reviens ici et choisis ce fichier avec le bouton « Choisir le fichier… » plus bas.

Le glisser ne marche pas ? Fais un clic droit sur la barre de favoris, « Ajouter une page » ou « Ajouter un favori », nomme-le « Exporter Kyara » et colle comme adresse le contenu du bouton « Copier l'adresse du favori ».

Méthode 2 · par la console du navigateur
  1. Va sur kyara.games en étant connecté.
  2. Ouvre la console :
    • Chrome, Edge, Brave, Opera, Vivaldi : Ctrl+Maj+J · Mac ⌘+⌥+J
    • Firefox : Ctrl+Maj+K · Mac ⌘+⌥+K
    • Safari : active d'abord Réglages → Avancés → « Afficher les fonctionnalités pour les développeurs web », puis ⌘+⌥+C
    • Partout ailleurs : clic droit sur la page → « Inspecter » (ou « Examiner l'élément »), puis l'onglet « Console »
  3. Colle la ligne ci-dessous et appuie sur Entrée. Si le navigateur affiche un avertissement sur le collage, tape à la main ce qu'il demande (allow pasting ou autoriser le collage), Entrée, puis colle à nouveau.
  4. Choisis le fichier kyara-collection.json téléchargé avec le bouton ci-dessous.

        

      

      
Sur téléphone, ni la console ni les favoris de ce type ne sont pratiques : fais l'export sur un ordinateur, puis envoie-toi le fichier.
